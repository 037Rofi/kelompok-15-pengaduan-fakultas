# Aplikasi Pengaduan dan Monitoring Permasalahan Fakultas Berbasis Mobile

Repository Kelompok 15 - Mikrokredensial

## Deskripsi
Aplikasi mobile yang memungkinkan mahasiswa melaporkan masalah fasilitas fakultas
(AC rusak, kursi patah, lampu mati, toilet kotor, dll.) dengan memfoto kondisi
fasilitas, lalu memantau perkembangan penanganannya hingga selesai.

## Alur Penggunaan
1. Mahasiswa login dengan NIM dan password.
2. Pilih menu **Buat Pengaduan**.
3. Foto fasilitas yang bermasalah melalui kamera aplikasi.
4. Isi kategori, lokasi (gedung/ruangan), dan deskripsi masalah.
5. Kirim laporan (status awal: **Menunggu**).
6. Admin memverifikasi dan mengubah status menjadi **Diproses**.
7. Mahasiswa memantau status lewat menu riwayat.
8. Setelah diperbaiki, status menjadi **Selesai** dan mahasiswa menerima notifikasi.
